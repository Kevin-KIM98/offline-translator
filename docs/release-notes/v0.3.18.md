**The short phrases an interpreter hears most.**

A sentence-level model with no context is at its weakest on set phrases, and OPUS-MT got many of
them wrong — sometimes reversing the meaning. Measured on the desktop through the engine, one
call per sentence as the app runs it:

| input | before |
| --- | --- |
| 안녕하세요. | Good evening. |
| 아니요 | Yes. (the opposite) |
| 싫어요. | Okay. (the opposite) |
| 목이 말라요. | Not the throat. |
| 예약했습니다. | Reservationd. |
| 연락드리겠습니다. | About Us |
| 계산해 주세요. | Please calculate. (계산 read as arithmetic) |
| 네, 알겠습니다. | Yes, sir. |
| No. | 아니. |
| Check, please. | 확인해 주세요. (= please verify) |
| The bill, please. | 빌, 제발 ("Bill" as a name) |
| This way, please. | 이쪽으로, please. |
| Turn right. | 오른쪽으로 돌려. (= rotate it) |
| How are you? / Follow me. | 잘 지냈어? / 따라와 (반말) |

`text::fixedTranslation` now holds 47 Korean→English and 67 English→Korean set phrases with a
fixed answer, checked per sentence in `NmtEngine::translateDirect` before the batch, so the pivot
hop of Korean→Thai gets them too. Matching ignores spacing, punctuation and case; a phrase inside
a longer sentence still goes to the model ("안녕하세요, 저는 김입니다." → "Hi, I'm Kim."); and an
entry whose meaning turns over when it is asked is left to the model then — "네?" stays
"Excuse me?", not "Yes." English→Korean answers in 존댓말 throughout.

Of 189 Korean probe sentences, 42 changed and 147 came through untouched. 403 unit checks pass.
Nothing was run on a phone.

This release also makes `tr_pipeline_translate_lines` — the one-call batch translation photo
translation uses — available to apps that link the released AAR; before it, they fell back to one
Marian call per piece of text.

Android: add the AAR to `app/libs`. iOS: add this repo as a Swift Package (tag v0.3.18).
